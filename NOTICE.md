# NOTICE

## `support.js`

`support.js` é o runtime interno do formato `.dc.html` (Claude/Anthropic Design
Components). É gerado automaticamente pela ferramenta que produz esse formato —
não faz parte do código-fonte de aplicação deste projeto e não deve ser editado
manualmente. Não há pasta de código-fonte, build config ou processo de rebuild
associado a ele neste repositório; trate-o como um asset vendored.
